# Catálogo de Carros Esportivos 🏎️

Projeto desenvolvido como atividade prática da disciplina de **Desenvolvimento Front-End para Web** (HTML5 puro).

## 📋 Sobre o Projeto
O site consiste em um catálogo interativo de carros esportivos de alta performance. Ele é composto por uma página inicial com a listagem dos veículos e páginas individuais de detalhes para cada modelo, contendo ficha técnica, imagens e vídeos incorporados do YouTube.

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estruturação semântica de todas as páginas (`<header>`, `<main>`, `<section>`, `<article>`, `<figure>`, `<iframe>`, etc.).
* **CSS:** *(Nenhum utilizado, foco total em marcação HTML conforme requisitos da atividade).*
